# GlucoTwin: Presentation Outline (export as PDF/PPT → docs/GlucoTwin_Presentation.pdf)

1. **Title:** GlucoTwin, team name, college, logo
2. **The Problem:** India's diabetes and prediabetes burden; one-size-fits-all diets fail
3. **Why Now:** wearables, AI, and digital twins make personalisation affordable
4. **Our Solution:** a virtual you that predicts glucose *before* you eat
5. **How It Works:** inputs → AI model → twin engine → what-if dashboard (use docs/architecture.png)
6. **AI/ML Details:** Gradient Boosting, 10 features, MAE ≈ 4.8 mg/dL, curve simulation
7. **Live Demo Screens:** baseline vs. twin's plan curve, recommendation card
8. **Outcomes:** predicted peak reduction from the plan, user empowerment
9. **Ethics & Limitations:** synthetic data, not medical advice, privacy-by-design
10. **Roadmap:** CGM calibration, wearables, Indian-food DB, multilingual LLM coach
11. **Team & Ask:** team, college/incubator, thank you
